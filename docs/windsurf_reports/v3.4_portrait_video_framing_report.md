## Problem Statement

### Visual Disconnect with Portrait Videos

**Observed Issue:**
Portrait-oriented advisor videos (e.g., "Pivot vs. Persevere") were rendering in widescreen containers optimized for 16:9 landscape media, creating:

| Problem | Visual Result | User Impact |
|---------|---------------|-------------|
| **Wide container (750px)** | Excessive black sidebars | Video feels distant |
| **16:9 aspect ratio** | Giant empty space | Poor emotional framing |
| **Cinematic scale** | Oversized player | Breaks calm advisory feel |
| **Widescreen optimization** | Awkward portrait framing | Feels like "media consumption" not "advisor guidance" |

**User Experience Impact:**
- Videos felt too large and disconnected
- Advisor appeared distant rather than conversational
- Black sidebars dominated the visual experience
- Framing felt awkward and unintentional
- Broke the calm, human-centered design philosophy

### Target Experience

**From:**
> "Large media player with excessive black space"

**To:**
> "Thoughtful advisor conversation, visually integrated and intentional"

### Portrait Video Mode Implementation

**New Parameter:** `portrait=True`

**Available in:**
- `render_video_embed()` - Base video embedding function
- `render_video_section()` - Complete video section with title and context

**Usage:**
```python
render_video_section(
    video_url=VIDEO_LINKS["recovery_pivot_persevere"],
    section_title="Pivot vs. Persevere (8 min)",
    intro_text="This video explores the critical decision...",
```

### Adaptive Sizing Logic

**Portrait Mode (`portrait=True`):**
```python
container_max_width = min(max_width, 580)  # Cap at 580px

iframe_height = 850  # Taller height for portrait
background_color = "#F7F9FC"  # Soft background
```

```python
container_max_width = max_width  # Full 750px

```

## Detailed Changes

### Enhanced `render_video_embed()` Function

**New signature:**
```python
def render_video_embed(video_url, title=None, subtitle=None, max_width=750, portrait=False):
```

**Adaptive sizing logic:**
```python
# Determine optimal sizing based on video orientation
if portrait:
    # Portrait mode: narrower container, taller aspect ratio
    container_max_width = min(max_width, 580)  # Cap at 580px for portrait
    aspect_padding = 177.78  # 9:16 aspect ratio for portrait videos
    iframe_height = 850  # Taller height for portrait videos
    background_color = "#F7F9FC"  # Soft background to reduce black sidebar impact
else:
    # Landscape mode: standard widescreen layout
    container_max_width = max_width
    aspect_padding = 56.25  # 16:9 aspect ratio for landscape videos
    iframe_height = 500
    background_color = "#F7F9FC"
```

**CSS improvements:**
```css
.video-container {
    max-width: {container_max_width}px;  /* 580px for portrait, 750px for landscape */
    margin: 1.5rem auto;
    padding: 0;
}

.video-wrapper {
    background: #FFFFFF;
    border: 1px solid #E1E8ED;
    border-radius: 12px;
    padding: {'0.75rem' if portrait else '1rem'};  /* Tighter padding for portrait */
    box-shadow: 0 2px 8px rgba(0, 0, 0, 0.04);
}

.video-frame {
    position: relative;
    width: 100%;
    padding-bottom: {aspect_padding}%;  /* 177.78% for portrait, 56.25% for landscape */
    height: 0;
    overflow: hidden;
    border-radius: 8px;
    background: {background_color};
}
```

**Mobile responsiveness:**
```css
@media (max-width: 768px) {
    .video-container {
        max-width: 100%;
        margin: 1rem auto;
    }
    
    .video-wrapper {
        padding: 0.75rem;
    }
    
    .video-frame {
        padding-bottom: {'133.33%' if portrait else '56.25%'};  /* 4:3 for mobile portrait */
    }
}
```

### Enhanced `render_video_section()` Function

**New signature:**
```python
def render_video_section(video_url, section_title="Introduction", 
                         intro_text=None, subtitle=None, max_width=750, portrait=False):
```

**Parameter pass-through:**

- Minimal black sidebars
- Taller vertical space

**Landscape Videos:**
- Max-width: 750px

- Centered horizontally
- Standard widescreen framing
- Standard vertical space

### Mobile Experience (≤768px)

**Portrait Videos:**
- Max-width: 100% (full width)
- Aspect ratio: 4:3 (133.33% padding)
- Centered horizontally
- Optimized for vertical screens
- Prevents excessive height

**Landscape Videos:**
- Max-width: 100% (full width)
- Aspect ratio: 16:9 (56.25% padding)
- Centered horizontally
- Standard mobile video framing
- Balanced height

**Mobile Optimization Rationale:**
- Portrait videos on mobile use 4:3 instead of 9:16 to prevent excessive vertical scrolling
- Landscape videos maintain 16:9 for optimal widescreen viewing
- Both orientations scale to full width for maximum screen utilization
