## UX Design Decisions

### **Collapsible Supplemental Section**

**Why collapsed by default?**
- Reduces initial visual clutter
- Focuses attention on core business-state pathways
- Maintains calm, organized sidebar
- Prevents menu overload

**Toggle Behavior:**
- ▶ icon when collapsed
- ▼ icon when expanded
- Full-width button for easy interaction
- State persists during session
- Smooth expand/collapse with rerun

### **Visual Hierarchy**

**Core vs. Supplemental:**
- Core: "Start [Name]" (action-oriented)
- Supplemental: "Explore [Name]" (learning-oriented)
- Clear section labels and captions
- Dividers separate sections
- Consistent card styling

**Calm Design Maintained:**
- No overwhelming long lists
- Intentional categorization
- Easy to scan
- Professional, lightweight feel
- Not developer-heavy or enterprise-like
