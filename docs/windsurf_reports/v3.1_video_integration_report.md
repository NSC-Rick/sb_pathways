## Conditional Video Loading

### Implementation Pattern

All pathway pages now use this pattern:

```python
if VIDEO_LINKS["pathway_intro"]:
    # Video URL exists - embed it
    st.components.v1.iframe(
        VIDEO_LINKS["pathway_intro"],
        height=VIDEO_HEIGHT,
        scrolling=False
    )
else:
    # No video URL - show placeholder
    render_video_placeholder("Introduction Video", "X minutes")
```

### Benefits

**Graceful degradation:**
- If video URL is empty, shows placeholder
- No broken embeds or errors
- Consistent user experience

**Future-ready:**
- Add video URL to `video_links.py`
- No code changes needed in pathway pages
- Automatic switch from placeholder to video

**Testing-friendly:**
- Can temporarily remove video by clearing URL
- Easy to test placeholder vs. embedded states
- No code modifications required
